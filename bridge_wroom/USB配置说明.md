# 音频桥 USB 配置

音频桥固件不再创建 Wi‑Fi 热点，也不再运行网页服务器。家庭 Wi‑Fi 只用于有道 TTS；所有配置通过 USB 数据线完成。

## 使用方法

1. 用数据线连接音频桥和电脑。
2. 关闭 Arduino IDE 的串口监视器，避免占用同一个 COM 端口。
3. 双击项目根目录的 `启动音频桥配置器.cmd`。
4. 选择带有 CH340、CH341、CP210x 或 USB Serial 描述的端口，点击“连接”。
5. 在图形窗口中配置 Wi‑Fi、选择蓝牙音响、更新 DeepSeek Key、测试 TTS 或读取板内日志。

串口速率固定为 115200。Wi‑Fi 密码和 API Key 使用十六进制传输，不会由固件回显或写入日志。

## 注意

- 选择/重新扫描蓝牙音响后，音频桥会自动重启；图形工具会继续使用同一个串口。
- 修改 DeepSeek Key 需要音频桥的 UART 已连接到 S3。
- 音频桥仍会把运行日志保存到 SPIFFS；“日志”页可读取、导出或清除。
