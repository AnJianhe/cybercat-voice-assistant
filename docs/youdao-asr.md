# 有道短语音识别接入

## 当前范围

- S3 本地执行 WakeNet 唤醒及 MultiNet 固定命令识别。
- 自由说话录音由 S3 直接通过 HTTPS 上传至有道 `/asrapi`。
- 有道返回文字后，原有 DeepSeek 流式接口生成回答，并打印 `ASR:` 与 `assistant:` 日志。
- 有道文字转语音服务已由用户在控制台开通，但本次尚未接入其流式合成协议。没有配置 Azure 合成凭据时，仅显示文字，不再请求空配置的 Azure 服务。

## 凭据

应用 ID 和应用密钥存放在 `master_s3/main/youdao_secrets.h`，该文件已被根目录 `.gitignore` 排除。构建副本中有对应的本地文件。不要分享此文件或含真实凭据的固件。没有该文件时可用空配置编译，但不会提交识别请求。

## 协议

- 16 kHz、16-bit、单声道 WAV，Base64 后按表单 URL 编码。
- 请求采用官方 `/asrapi` SDK 示例中的 `signType=v2`。
- SHA-256 签名输入是：应用 ID + 截断后的 Base64 文本 + UUID salt + 秒级时间戳 + 应用密钥。
- 截断规则：长度超过 20 时取前 10 字符、十进制原长度、后 10 字符。
- 发送前等待有效系统时间，HTTPS 使用 ESP-IDF 证书包，不关闭证书验证。
- WAV/Base64 使用 PSRAM；URL 编码分块写出，避免额外分配整个转义后的请求体。
- 处理部分写入、内存分配失败、非 200 状态、截断响应、错误码及空识别结果，不输出密钥或签名原文。
