# 板载唤醒彩灯（GPIO48 测试接法）

## 接法与范围

用户确认 GPIO48 未连接其他外设，允许按所贴 DevKitC 示例测试。N16R8/IC 编号本身不能确认具体开发板型号；GPIO48 是否连接板载 WS2812 RGB 灯仍需要实物观察验证。不自动扫描或改试 GPIO38。

配置文件为 `master_s3/main/wake_led_config.h`，`WAKE_LED_GPIO=48`。这是真实 GPIO，不使用 Arduino 虚拟编号 97。设置 `-1` 可禁用。驱动拒绝非 48/38 的测试配置，以及与现有麦克风/UART 引脚冲突的配置。

## 提示行为

- 启动期间关闭彩灯；语音模型和采集就绪后显示低亮度蓝色。
- 检测到“小爱同学”立即切换绿色，并保持到本次对话结束。
- 识别不到有效指令，或本机生成回复失败：红色持续 3 秒，再恢复蓝色。
- 没有网络、有道/DeepSeek API、HTTP 或流中断等后端故障：红绿交替闪烁 3 秒（每 250 毫秒换色），再恢复蓝色。
- 识别到固定离线指令（例如“打开空调”）：粉色持续 3 秒，再恢复蓝色。粉色只表示命令已在 S3 本地识别，不等于下游设备已经执行成功。
- DeepSeek 完整回复成功后直接恢复蓝色。
- 新一次唤醒会立即打断旧灯效并更新会话标识，旧回复结束不会误清除新会话的绿灯。

USB 测试命令 `LED_TEST_RED`、`LED_TEST_BACKEND`、`LED_TEST_PINK` 可分别验证三种 3 秒灯效，不写入对话记录。

## 实现

使用 ESP-IDF 5.4.4 RMT 发送单颗 WS2812 的 GRB/MSB-first 帧，10 MHz 时基，0 位 0.3/0.9 微秒、1 位 0.9/0.3 微秒，帧尾低电平 300 微秒。整个 25-symbol 帧保存在内部 RAM，RMT 发送完成前不改动。

独立 LED 任务接收状态通知，不在实时音频识别任务中等待灯光发送。初始化或发送失败只禁用/报告灯光功能，不让语音助手崩溃。日志保存格式和原有模型不变。

时序参考：[ESP-IDF 5.4.4 RMT LED 示例](https://github.com/espressif/esp-idf/blob/v5.4.4/examples/peripherals/rmt/led_strip/main/led_strip_encoder.c)。软件日志中的状态只证明驱动请求/传输完成，不能代替实物看到正确颜色。
