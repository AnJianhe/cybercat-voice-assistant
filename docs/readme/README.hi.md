# CyberCat वॉइस असिस्टेंट

ESP32 पर आधारित वॉइस असिस्टेंट संदर्भ परियोजना: S3 आवाज़ और क्लाउड संभालता है, WROOM Bluetooth ऑडियो और C3 ESP-NOW तथा इन्फ्रारेड नियंत्रण संभालता है।

## घटक

- `master_s3/`: वेक वर्ड, वाक् पहचान, DeepSeek चैट और TTS।
- `bridge_wroom/`: TF ऑडियो, PCM और Bluetooth Classic A2DP।
- `slave_c3/`: ESP-NOW, इन्फ्रारेड सीखना और प्रसारण।

## शुरुआत

पहले [कॉन्फ़िगरेशन](../configuration.md), [वायरिंग](../wiring.md) और [बिल्ड व फ्लैश](../build-and-flash.md) पढ़ें। विस्तृत गाइड अभी केवल सरल चीनी में हैं। अपने क्लाउड क्रेडेंशियल इस्तेमाल करें; API कुंजी, लॉग या रिकॉर्डिंग प्रकाशित न करें।

कंट्रोल सेंटर 20 भाषाएँ समर्थित करता है, जिनमें अरबी दाएँ-से-बाएँ लेआउट शामिल है। ऑडियो ब्रिज USB से कॉन्फ़िगर होता है; [USB गाइड](../../bridge_wroom/USB配置说明.md) देखें।
