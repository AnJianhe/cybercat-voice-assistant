# ผู้ช่วยเสียง CyberCat

โครงการอ้างอิงผู้ช่วยเสียง ESP32: S3 ดูแลเสียงพูดและคลาวด์, WROOM ดูแลเสียง Bluetooth และ C3 ให้บริการ ESP-NOW กับการควบคุมอินฟราเรด

## ส่วนประกอบ

- `master_s3/`: คำปลุก การรู้จำเสียง แชต DeepSeek และ TTS
- `bridge_wroom/`: เสียง TF, PCM และ Bluetooth Classic A2DP
- `slave_c3/`: ESP-NOW การเรียนรู้และส่งคำสั่งอินฟราเรด

## เริ่มต้น

อ่าน [การตั้งค่า](../configuration.md), [การต่อสาย](../wiring.md) และ [การสร้างและแฟลช](../build-and-flash.md) ก่อน คู่มือโดยละเอียดยังมีเฉพาะภาษาจีนตัวย่อ โปรดใช้ข้อมูลรับรองคลาวด์ของคุณเอง และอย่าเผยแพร่ API key, log หรือไฟล์บันทึกเสียง

ศูนย์ควบคุมรองรับ 20 ภาษา รวมถึงเลย์เอาต์ภาษาอาหรับจากขวาไปซ้าย ตั้งค่าบริดจ์เสียงผ่าน USB ดู[คู่มือ USB](../../bridge_wroom/USB配置说明.md)
