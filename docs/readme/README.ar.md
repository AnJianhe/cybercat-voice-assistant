# مساعد CyberCat الصوتي

مشروع مرجعي لمساعد صوتي يعمل بـ ESP32: يتولى S3 الصوت والخدمات السحابية، ويتولى WROOM صوت Bluetooth، بينما يوفر C3 اتصال ESP-NOW والتحكم بالأشعة تحت الحمراء.

## المكونات

- `master_s3/`: كلمة التنبيه والتعرف على الكلام ومحادثة DeepSeek وTTS.
- `bridge_wroom/`: صوت TF وPCM وBluetooth Classic A2DP.
- `slave_c3/`: ESP-NOW وتعلّم أوامر الأشعة تحت الحمراء وإرسالها.

## البدء

اقرأ أولاً [الإعداد](../configuration.md) و[التوصيلات](../wiring.md) و[البناء والبرمجة](../build-and-flash.md). الأدلة التفصيلية متاحة حالياً بالصينية المبسطة. استخدم بيانات اعتمادك السحابية ولا تنشر مفاتيح API أو السجلات أو التسجيلات.

يدعم مركز التحكم 20 لغة، ويستخدم تخطيطاً عربياً من اليمين إلى اليسار. يُضبط جسر الصوت عبر USB؛ راجع [دليل إعداد USB](../../bridge_wroom/USB配置说明.md).
