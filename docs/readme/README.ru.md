# Голосовой помощник CyberCat

Справочный проект голосового помощника на ESP32: S3 отвечает за речь и облако, WROOM — за Bluetooth-аудио, C3 — за ESP-NOW и инфракрасное управление.

## Компоненты

- `master_s3/`: ключевое слово, распознавание речи, чат DeepSeek и TTS.
- `bridge_wroom/`: TF-аудио, PCM и Bluetooth Classic A2DP.
- `slave_c3/`: ESP-NOW, обучение и передача инфракрасных команд.

## Начало работы

Сначала прочитайте [настройку](../configuration.md), [подключение](../wiring.md) и [сборку и прошивку](../build-and-flash.md). Подробные руководства пока доступны только на упрощённом китайском. Используйте собственные облачные ключи и не публикуйте API-ключи, журналы или записи.

Центр управления поддерживает 20 языков, включая арабский интерфейс справа налево. Аудиомост настраивается через USB; см. [руководство USB](../../bridge_wroom/USB配置说明.md).
