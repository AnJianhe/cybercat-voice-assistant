# S3 直连喇叭模式

控制中心“服务与测试”选择“直连喇叭（仅 S3）”，保存后立即生效并保存在 NVS。默认保留“蓝牙音箱（WROOM）”。正在合成或播放时拒绝切换。

直连模式：S3 请求有道 WAV，直接向 I2S 功放输出 PCM，不依赖 WROOM、经典蓝牙或 TF 卡。麦克风使用 I2S0，喇叭使用 I2S1。

## 外接 MAX98357A I2S 功放模块

| S3 | 功放模块 |
|---|---|
| GPIO15 | BCLK / BCK |
| GPIO16 | LRC / LRCLK / WS |
| GPIO7 | DIN |
| GND | GND |
| 5V（按模块额定供电） | VIN |

喇叭只连接功放的 SPK+ 和 SPK-，SPK- 不能接 GND。不能将裸喇叭直接接 GPIO；GPIO 数据电平为 3.3V，不能灌入 5V。若模块有 SD/EN 或 GAIN，按该模块说明设置。接线时断电。

这些引脚不占用现有麦克风 GPIO4/5/6、UART GPIO17/18、状态灯 GPIO48。蓝牙模式下保留原来的 S3 与 WROOM 接线。

蓝牙模式会先把 WAV 下载到 S3 PSRAM，未知长度按需扩容，最多 3 MB；桥确认音频排空后才报告完成。已知音频过大或初始 PSRAM 分配失败时回退为流式路径；下载中扩容失败则明确报告失败。喇叭模式保持流式播放。两种路径都不把 TTS 写入片内 Flash，也不关闭 S3 Wi‑Fi 或 ESP-NOW。

## 验证边界

串口显示 I2S 初始化和 PCM 写入成功，只验证数字输出链路。没有接好功放和喇叭时，不能据此声称实物已出声。
